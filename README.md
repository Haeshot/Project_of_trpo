## Игра 1: Sky Jumper

**Sky Jumper** — это бесконечный вертикальный платформер, в котором игрок прыгает вверх по генерируемым платформам. При наборе высоты меняются локации (лес, пустыня, снег, космос), каждая со своей графикой, частицами и стилем платформ.

### Особенности
- Бесконечная генерация платформ.
- Динамическая камера, следующая за игроком.
- 4 детализированные локации с уникальными:
  - фонами (градиенты, горы, звёзды);
  - платформами (дерево, камень, лёд, металл);
  - декорациями (кусты, кактусы, сугробы, планеты);
  - системами частиц (листья, песок, снег, звёзды).
- Персонаж с анимациями (прыжок, падение, моргание) и аксессуарами в зависимости от локации (капюшон, шляпа, шапка, шлем).
- Подсчёт высоты (очков).
- Game Over и перезапуск.

### Файлы
- `skyjumper_main.cpp` — основной код игры (предполагается, что вы его сгенерировали ранее).
- `game_logic.h` — объявления функций для определения локации и цвета текста.
- `test_skyjumper.c` — юнит-тесты для логики смены локаций и цветов UI (CUnit).

## Игра 2: Super Mario (Minecraft Style)

Это платформер в стиле классической *Super Mario*, но с пиксельной графикой, вдохновлённой *Minecraft*. Игрок управляет персонажем, собирает монеты, уничтожает врагов и проходит 5 уровней, в конце каждого нужно коснуться флага.

### Особенности
- 5 предустановленных уровней.
- Враги (слизни), передвигающиеся по платформам.
- Монеты, сердечки (система жизней).
- Детализированный персонаж с мимикой, анимацией ходьбы и прыжка.
- Враги с анимацией подпрыгивания и "злыми" глазами.
- Облака на фоне.
- Меню выбора после завершения уровня (следующий уровень / выход).

### Файлы
- `mario.cpp` — первая версия игры.
- `test.cpp` — улучшенная версия с более проработанной графикой персонажа и врагов.

> **Примечание:** Файлы `mario.cpp` и `test.cpp` являются разными итерациями. Для сборки используйте любой из них.

## Модульные тесты (CUnit)

Для проверки логики **Sky Jumper** написаны тесты с использованием фреймворка **CUnit**. Они проверяют:
- Функцию `GetLocationByScore` — правильное определение локации по высоте (включая циклическое зацикливание каждые 4000 очков).
- Функцию `GetUITextColor` — возврат корректного цвета текста для каждой локации.

Файл `test_skyjumper.c` содержит все тесты. Для их запуска требуется установленная библиотека **CUnit** (см. [инструкцию](https://sourceforge.net/projects/cunit/)).

## Сборка и запуск

### Windows (MSVC или MinGW)
1. Установите **RayLib** (например, через vcpkg или скачав бинарники).
2. Установите **CUnit** (только для тестов Sky Jumper).
3. Скомпилируйте нужный проект.

**Пример компиляции Sky Jumper (без тестов):**
```bash
g++ -o skyjumper skyjumper_main.cpp -lraylib -lm
```

**Пример компиляции Super Mario:**
```bash
g++ -o mario mario.cpp -lraylib -lopengl32 -lgdi32 -lwinmm  # Windows
# или для Linux/macOS:
g++ -o mario mario.cpp -lraylib -lm
```

**Запуск тестов (Sky Jumper):**
```bash
g++ -c skyjumper_main.cpp -o skyjumper.o
gcc -c test_skyjumper.c -o test_skyjumper.o -I/path/to/raylib/include -I/usr/include/CUnit
g++ -o run_tests skyjumper.o test_skyjumper.o -lraylib -lCUnit -lm
./run_tests
```

## Управление

### Sky Jumper
- **Влево / Вправо** — стрелки или A / D.
- **Перезапуск после Game Over** — клавиша `R`.

### Super Mario
- **Влево / Вправо** — стрелки или A / D.
- **Прыжок** — пробел (Space).
- **Выбор в меню после уровня** — стрелки ВВЕРХ/ВНИЗ (или W/S), подтверждение — ENTER / SPACE.
- **Рестарт после победы/поражения** — `R`.
- **Выход из игры** — ESC.

## Требования

- Операционная система: Windows, Linux, macOS.

- Библиотека **RayLib** (последняя стабильная версия).
- **CUnit** (только для сборки и запуска тестов).
- Аудиоустройство (для звуковых эффектов, если они включены).
